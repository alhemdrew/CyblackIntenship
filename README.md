# CyBlack Internship – January 2026 Cohort

![CyBlack Logo](https://cyblack.org/storage/2023/04/cyblack_logo_white.png)

This repository is a curated collection of projects, reports, and exercises produced during the CyBlack January 2026 internship. It showcases the hands-on experience gained in threat intelligence, security operations, cloud & identity management, GRC fundamentals, and collaborative sprint-based workflows.

All materials were developed as part of the intensive, fast-paced program designed to build industry-ready cybersecurity talent.

**Note:** Each sprint folder contains the work and deliverables completed during that period.
