This repository is a curated collection of projects, reports, and exercises produced during the CyBlack January 2026 internship. 
It showcases the hands-on experience gained in threat intelligence, security operations, cloud & identity management, GRC fundamentals, and collaborative sprint-based workflows.

All materials were developed as part of the intensive, fast-paced program designed to build industry-ready cybersecurity talent.

**Note:** Each sprint folder contains the work and deliverables completed during that period:

- [Sprint 2](https://github.com/alhemdrew/CyblackIntenship/tree/main/sprints/sprint3) – GRC
- [Sprint 2](https://github.com/alhemdrew/CyblackIntenship/tree/main/sprints/sprint4) – Human Factor
